# MakeHuman assets (CC0)

From https://github.com/makehumancommunity/makehuman (`makehuman/data`), released under
CC0 1.0 (see `LICENSE-CC0.md`): the hm08 base mesh, the default skeleton and its weights,
and the macro targets used to shape 李澤言 (young adult man, tall, athletic, lean).
`blender/character.py` builds `lizeyan.glb` from them.
